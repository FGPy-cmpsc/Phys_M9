# Моделирование оптических систем методом трассировки лучей

Проект моделирует ход лучей через три оптические системы - одиночную тонкую линзу, микроскоп (объектив + окуляр) и одиночную толстую сферическую линзу - методом численной трассировки большого количества лучей от каждой точки светящегося предмета. На экране собирается изображение, по которому оценивается увеличение и качество (размытие, аберрации).

## 1. Установка и использование

### Шаг 1. Клонировать проект

```bash
git clone https://github.com/FGPy-cmpsc/Phys_M9.git
cd Phys_M9
```

### Шаг 2. Создать и активировать виртуальное окружение

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Шаг 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### Шаг 4. Запустить программу

Демонстрация трёх систем (тонкая линза, микроскоп, толстая линза) с сохранением графика в `demo_output/`:

```bash
python3 demo.py
```

Расчёт одной системы с параметрами по умолчанию (тонкая линза):

```bash
python3 main.py
```

Расчёт с произвольными параметрами:

```bash
python3 main.py --system thin --lens-f 0.10 --object-distance 0.30 --output trace_thin
python3 main.py --system microscope --object-distance 0.0229 --object-size 0.0008 --output trace_micro
python3 main.py --system thick --lens-R1 0.10 --lens-R2 -0.10 --lens-thickness 0.020 --output trace_thick
```

Развёртка по толщине и апертуре толстой линзы (тепловые карты размытия и сбора света):

```bash
python3 scan.py
python3 scan.py --thickness-steps 12 --aperture-steps 12 --rays-per-point 400
```

## 2. Тесты

Набор из 40 автотестов проверяет корректность формул, физики преломления, трассировки и валидации входных параметров.

```bash
python3 -m unittest -v test_optics.py
```

Что покрывают тесты:

* формула тонкой линзы 1/f = 1/d + 1/d' и формула увеличения
* частные случаи: предмет в фокусе даёт изображение в бесконечности, предмет на 2f даёт увеличение -1
* трассировка центрального луча через центр линзы
* закон Снеллиуса для сферической поверхности (отдельная единичная проверка)
* нормальное падение луча на сферическую поверхность не меняет направление
* построение системы по конфигурации (тонкая линза, микроскоп, толстая)
* формула линзовара для толстой линзы в пределе тонкой линзы
* валидация: NaN, inf, отрицательные значения, неизвестная система, недопустимые комбинации (предмет в фокусе, апертура больше радиуса, толщина больше радиуса, линзы микроскопа слишком близко)
* валидация выходного префикса (пустой, абсолютный путь, "..", запрещённые символы, длина)
* валидация JSON-конфига (отсутствующий файл, битый JSON)
* сохранение и загрузка конфигурации
* построение объекта-стрелки

## 3. Входные параметры

Параметры задаются через аргументы командной строки. Источник света - равномерно светящийся плоский предмет в форме стрелки, лучи из каждой точки разлетаются в случайный конус, направленный к апертуре первой линзы. Это имитирует свечение во все стороны видимого диапазона телесных углов.

### Общие параметры (`main.py`)

* `--system` - тип системы: `thin`, `microscope` или `thick`
* `--object-distance` - расстояние от предмета до первого элемента, м
* `--object-size` - размер предмета (сторона квадрата), м
* `--screen-distance` - расстояние от последнего элемента до экрана (0 = автоматически по теории), м
* `--object-resolution` - разрешение объекта (предмет - растровая стрелка `N×N` пикселей)
* `--rays-per-point` - число лучей, выпускаемых из каждой светящейся точки предмета
* `--output` - префикс выходных файлов (PNG-график и JSON-сводка)
* `--config` - путь к JSON-файлу с параметрами (значения из файла можно переопределять флагами)

### Параметры тонкой линзы (`--system thin`)

* `--lens-f` - фокусное расстояние, м
* `--lens-aperture` - радиус апертуры, м

### Параметры микроскопа (`--system microscope`)

* `--f-obj` - фокусное расстояние объектива, м
* `--f-oc` - фокусное расстояние окуляра, м
* `--obj-to-oc` - расстояние между линзами, м
* `--obj-aperture` - радиус апертуры объектива, м
* `--oc-aperture` - радиус апертуры окуляра, м

### Параметры толстой линзы (`--system thick`)

* `--lens-R1` - радиус первой поверхности, м (положительный = выпуклая)
* `--lens-R2` - радиус второй поверхности, м (отрицательный = выпуклая)
* `--lens-thickness` - толщина линзы по оси, м
* `--lens-n` - показатель преломления стекла
* `--lens-thick-aperture` - радиус апертуры, м

### Развёртка (`scan.py`)

* `--thickness-min`, `--thickness-max`, `--thickness-steps` - диапазон по толщине
* `--aperture-min`, `--aperture-max`, `--aperture-steps` - диапазон по апертуре
* `--object-distance`, `--object-size`, `--lens-R1`, `--lens-R2`, `--lens-n` - фиксированные параметры толстой линзы
* `--object-resolution`, `--rays-per-point` - параметры расчёта изображения

## 4. Ограничения входных данных

Программа выполняет полную валидацию входных параметров и выводит понятное сообщение об ошибке до начала расчёта.

### Общие диапазоны

* `object_distance` в [1e-3, 100] м
* `object_size` в [1e-6, 1] м
* `object_resolution` в [5, 200]
* `rays_per_point` в [10, 100 000]
* `object_resolution²·rays_per_point` ≤ 5e6 (защита от перерасхода памяти)
* `screen_distance` ≥ 0 и ≤ 100 м

### Тонкая линза

* `lens_f` в [1e-3, 10] м
* `lens_aperture` в [1e-4, 0.5] м
* `object_distance > lens_f` (иначе изображение мнимое и не строится на экране)

### Микроскоп

* `f_obj`, `f_oc` в [1e-3, 10] м
* `obj_to_oc` в [1e-3, 100] м, и обязательно `obj_to_oc > f_obj + f_oc` (иначе промежуточное изображение не попадёт в окуляр)
* `obj_aperture`, `oc_aperture` в [1e-4, 0.5] м
* `object_distance > f_obj`

### Толстая линза

* `lens_n` в [1.0, 3.0]
* `lens_thickness` в [1e-4, 0.5] м, и `lens_thickness < min(|R1|, |R2|)`
* `lens_thick_aperture` в [1e-4, 0.5] м, и `aperture ≤ min(|R1|, |R2|)` (иначе сферическая поверхность не покрывает апертуру)

### Префикс выходных файлов

* не пустой и не длиннее 100 символов
* не абсолютный путь
* не содержит `..`
* только буквы латинского алфавита, цифры, `_`, `-`, `.`, `/`

### Конфиг-файл

* существует и доступен на чтение
* корректный JSON

Все числовые параметры должны быть конечными (не NaN и не inf).

## 5. Что считает программа

* строит предмет в виде растровой стрелки `N×N` пикселей
* от каждой светящейся точки выпускает `rays_per_point` лучей в конус, направленный на апертуру первой линзы (методом Монте-Карло)
* трассирует каждый луч через все оптические поверхности:
    * тонкая линза: параксиальная формула с обнулением преломления вне апертуры
    * сферическая поверхность: пересечение луча со сферой, преломление по закону Снеллиуса в 3D
    * толстая линза: последовательное преломление на двух сферических поверхностях
* собирает изображение на экране (заданном или вычисленном теорией), считает попадания в пиксели
* выводит сравнение теоретического и численно измеренного увеличения, поле зрения, число прошедших лучей

В `scan.py` строит карты RMS-размытия пятна изображения и виньетирования (числа лучей, дошедших до экрана) на плоскости (толщина, апертура) для толстой линзы - это наглядно показывает, как качество изображения зависит от сферической аберрации и сбора света.

## 6. Структура файлов

* `config.py` - конфигурация, валидация параметров, пределы для всех исполняемых файлов
* `optics.py` - модели оптических элементов: `ThinLens`, `SphericalSurface`, `ThickLens`, `Screen` и общая функция `trace_through_system`
* `systems.py` - сборка готовых оптических систем по конфигурации (тонкая, микроскоп, толстая)
* `tracer.py` - построение объекта-стрелки и формирование изображения на экране методом Монте-Карло
* `main.py` - основная программа с визуализацией одной системы (ход лучей, предмет, изображение, теор. и числ. увеличение)
* `demo.py` - демонстрация всех трёх систем рядом
* `scan.py` - развёртка по толщине и апертуре толстой линзы (карты размытия и сбора света)
* `test_optics.py` - автотесты
